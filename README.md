# 🚀 Fundamentos de Node.js

Este repositorio contiene mis prácticas, apuntes y proyectos realizados durante el curso de **Fundamentos de Node.js** en Platzi.

## 📚 Lo aprendido

Durante este curso trabajé conceptos esenciales del entorno de ejecución Node.js, incluyendo:

* ⚙️ Qué es Node.js y cómo funciona
* 📦 Manejo de módulos
* 🧠 Sistema de eventos
* 📁 Lectura y escritura de archivos con `fs`
* 🌐 Creación de servidores básicos
* 🔄 Programación asíncrona
* 🧵 Callbacks, Promesas y Async/Await
* 📡 Manejo de procesos
* 🛠️ Uso de npm y scripts
* 🚀 Buenas prácticas en backend con JavaScript

## ▶️ Instalación

Clona este repositorio:

```bash
git clone TU-URL-DEL-REPOSITORIO
```

Ingresa a la carpeta del proyecto:

```bash
cd fundamentos-nodejs
```

Instala las dependencias:

```bash
npm install
```

## 🚀 Ejecución

Para ejecutar un archivo:

```bash
node nombre-del-archivo.js
```

O usando scripts de npm:

```bash
npm run dev
```
